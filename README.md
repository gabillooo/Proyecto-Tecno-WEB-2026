# PermisosApp - Sprint 1 Administrativo

Panel administrativo de Permisos, Licencias y Patentes. No expone rutas ni vistas de ciudadanía y funciona con datos locales.

## Inicio rápido

```bash
npm install
npm start
```

- Cualquier correo y contraseña permiten entrar a la demostración administrativa.

El proyecto demuestra formularios reactivos y bidireccionales, interpolación, property/event binding, referencias locales y `ViewChild`, directivas estructurales, servicios inyectados, observables, una promesa, guards, DTOs, interfaces y enums.

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 15.2.11.
